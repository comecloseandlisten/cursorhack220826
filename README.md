## Как работаем

1. Не коммитим напрямую в `main` — только через Pull Request.
2. Ветка: `feat/<короткое-имя>`, `fix/<…>`, `chore/<…>`.
3. Перед PR — `git pull origin main` и проверка, что локально всё собирается.
4. Ревью: минимум 1 апрув от другого участника команды.

Полный процесс: [CONTRIBUTING.md](./CONTRIBUTING.md)
