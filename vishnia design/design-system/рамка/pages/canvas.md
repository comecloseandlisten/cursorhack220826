# Canvas Page Overrides

> Overrides MASTER. This is a canvas, not a landing page or bento.

## Layout

- Full viewport canvas. No max-width column. No card grid.
- Items are free-positioned and draggable.
- Chrome: date + day strip + add. Nothing else.

## Color

- Cool monochrome atmosphere: ice blue, white glass, navy text.
- Real family media stays in full color.

## Glass

- Liquid-glass controls use 24px backdrop blur, translucent white and a white rim.
- Glass requires the ambient blue light field underneath; never place it on flat white.
- Bottom controls form one visual dock: playback, calendar, phrases.

## Media behavior

- Initial state is a centered photo pile.
- One action expands the pile into a clean 3-column viewing grid.
- Dragging any photo exits automatic layout and enables free canvas placement.

## Type

- Inter only.
- No decorative labels.

## Rejected from MASTER

- Vibrant & block-based
- Hero / testimonials / CTA
- 1200px centered sections
