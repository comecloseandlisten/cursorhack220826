# AGENTS.md

Контекст для Cursor Agent в этом репозитории.

## Проект

- Хакатон-репозиторий на **4 человек**.
- Remote: `https://github.com/comecloseandlisten/cursorhack220826.git`
- Ветка по умолчанию: `main`
- Язык общения команды: русский; код и коммиты — по договорённости из CONTRIBUTING.md

## Обязательные правила

1. Не коммитить без явной просьбы пользователя.
2. Не пушить в `main` в обход PR-процесса команды.
3. Не коммитить секреты (`.env`, ключи API, токены).
4. Перед большими правками сверяться с `TEAM.md` (кто за какую зону отвечает).
5. Менять чужую зону ответственности только по запросу пользователя / после согласования.

## Пока стек не выбран

- Не выдумывать полноценное приложение «на всякий случай».
- Можно править только подготовительные файлы команды (README, TEAM, CONTRIBUTING, rules, .gitignore), пока пользователь не задаст продукт и стек.

## После появления кода

- Следовать существующему стилю проекта.
- Минимальный дифф: без лишних рефакторингов и новых markdown-файлов без запроса.
- Для UI — соблюдать frontend design rules пользователя (если они активны в чате).
