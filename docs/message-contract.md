# Контракт сообщения

Источник правды для модели, API, бота и UI. Поля со `*` — опциональны. Сообщение без `id` не существует: `id` выдаёт система.

Коммент (US-4) — это то же сообщение с заполненным `parentMessageId`.

```
Message
├── id
├── text?                          // 1. Text message
│   ├── fontType*                  // 1.1
│   ├── design*
│   └── size*
├── revealAnimation*               // 1.2
├── media[]                        // 2. mp4 | mp3 | jpeg | png | gif
├── dateTimeSend                   // 3
├── canvasId                       // 4
├── dateTimeReveal?                // 5  отложенные
├── senderId                       // 6
├── parentMessageId?               // 7  треды как в Obsidian
├── canvasPosition*                // 8  { x, y }
└── tag?                           // 9
```

Пустое тело запрещено: нужен непустой `text` и/или хотя бы один `media`.

---

## Поля

| Поле | Обяз. | Тип | Правила |
|------|-------|-----|---------|
| `id` | да, система | string | Не принимает клиент при создании. |
| `text` | если нет media | string | Трим. Пустая строка = нет текста. |
| `text.fontType` * | нет | string | Только вместе с `text`. |
| `text.design` * | нет | string | Начертание / стиль. Только с `text`. |
| `text.size` * | нет | number | Только с `text`. |
| `revealAnimation` * | нет | string | Имя анимации появления. Нет значения = без анимации. |
| `media` | если нет text | `{ mime, url }[]` | mime ∈ `video/mp4`, `audio/mpeg`, `image/jpeg`, `image/png`, `image/gif`. Пустой массив = нет медиа. |
| `dateTimeSend` | да | ISO-8601 | Время отправки. Ставит сервер. Не путать с reveal. |
| `canvasId` | да | string | Сообщение принадлежит одному канвасу. Смена канваса — отдельная операция. |
| `dateTimeReveal` | нет | ISO-8601 | Отложенное. `null`/нет поля = показать сразу (`dateTimeSend`). Должно быть ≥ `dateTimeSend`. До этого момента в UI скрыто (или плейсхолдер «закроется в …»). |
| `senderId` | да | string | Автор. Ставит сервер из сессии / бота. |
| `parentMessageId` | нет | string \| null | См. ниже. `null` = корень на канвасе. |
| `canvasPosition` * | нет | `{ x: number, y: number }` | Координаты карточки на канвасе. Нет значения — система кладёт рядом с родителем или в дефолтную точку. |
| `tag` | нет | string \| null | Один тег. Пусто = без тега. |

---

## ParentMessageId — как выбрать (треды как в Obsidian)

Родителя **не угадываем**. Его явно выбирает пользователь, как блок в Obsidian: фокус на карточке → новый блок становится дочерним.

| Действие | `parentMessageId` |
|----------|-------------------|
| Новое сообщение, ничего не выбрано | `null` (корень) |
| Выбрана карточка → Reply / вложенный блок | `id` выбранной карточки |
| US-4 Коммент | `id` сообщения, к которому пишут |
| В чате: reply / thread на сохранённое сообщение | `id` того сообщения в digest |
| В чате: обычное сообщение без reply | `null` |

Ограничения:

- Родитель должен существовать и быть на **том же** `canvasId`.
- Циклы запрещены (нельзя стать предком самому себе).
- Глубина не режется: дерево как вложенные блоки Obsidian.
- Дети ездят с родителем: если сдвинули родителя, `canvasPosition` детей смещается на тот же Δ, пока у ребёнка нет своего ручного якоря. Если `canvasPosition` задан явно — карточка стоит где поставили, связь треда остаётся.
- Удаление родителя не удаляет детей: дети становятся корнями (`parentMessageId = null`), остаются на канвасе.

В UI: у выбранной карточки виден индикатор «reply →»; composer показывает, к чему привяжется сообщение; крестик сбрасывает в корень.

## JSON

```json
{
  "id": "msg_…",
  "text": {
    "body": "…",
    "fontType": "serif",
    "design": "italic",
    "size": 16
  },
  "revealAnimation": "fade",
  "media": [{ "mime": "image/png", "url": "…" }],
  "dateTimeSend": "2026-08-22T14:20:00+07:00",
  "canvasId": "canvas_…",
  "dateTimeReveal": null,
  "senderId": "user_…",
  "parentMessageId": null,
  "canvasPosition": { "x": 120, "y": 80 },
  "tag": "note"
}
```

Клиент на create шлёт всё кроме `id`, `dateTimeSend`, `senderId`. Сервер их проставляет.
